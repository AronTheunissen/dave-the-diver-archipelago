# client/lib/ — Required DLLs

These DLLs must be copied here before building. They are NOT included in the repository.

## BepInEx DLLs
Copy from your BepInEx installation (`<GamePath>/BepInEx/core/`):
- `BepInEx.dll`
- `BepInEx.Unity.IL2CPP.dll`
- `HarmonyX.dll`
- `Il2Cppcorlib.dll`

## Game Interop DLLs (interop/ subfolder)
Generated by BepInEx after running the game once with BepInEx installed.
Copy from `<GamePath>/BepInEx/interop/` into `client/lib/interop/`:
- `Assembly-CSharp.dll`
- `UnityEngine.dll`
- `UnityEngine.CoreModule.dll`
- (any other assemblies referenced by the mod)

## How to get these
1. Install BepInEx 6 IL2CPP to your Dave the Diver game directory
   - Download from: https://github.com/BepInEx/BepInEx/releases
2. Launch Dave the Diver once — BepInEx will generate interop assemblies
3. Copy the files as described above
4. Copy `GamePath.props.example` to `GamePath.props` and set your game path
5. Run `dotnet build` in the `client/DaveDiverAP/` directory
