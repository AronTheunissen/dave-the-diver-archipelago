# Recipe Max Upgrade Levels

Max levels sourced from the recipe spreadsheet (Google Sheets, 2026-07-07) and cross-checked against `dish_upgrade_locations` in `locations.py`.

- Dishes with **Max Level 1** have no upgrades and should NOT be added to `dish_upgrade_locations`.
- Dishes with **Max Level 2+** should be added.
- Spreadsheet `Max Lvl Recipe` column = total levels including level 1 (i.e. max upgrades = max level − 1).
